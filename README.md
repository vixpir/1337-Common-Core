# 1337 Common Core Portfolio 💻

## Description
This repository contains all the projects completed during the Common Core curriculum at 1337 (42 Network). The curriculum focuses on C programming, memory management, algorithms, and system architecture, progressively building up to more complex Python and full-stack projects.

### Projects List:

*   **[Libft](./Libft/):** Creating my very first own C library, implementing numerous general-purpose functions from standard libc and linked list manipulations.
*   **[ft_printf](./ft_printf/):** Reimplementation of `printf` with support for mandatory C-format conversions.
*   **[push_swap](./push_swap/):** Project folder reserved for the upcoming sorting-algorithm project.
*   *(More projects will be added here as I progress...)*

## Instructions
To compile and test any specific project, navigate to its respective directory and use the provided `Makefile`.

Example for **Libft**:
```bash
cd Libft
make
```
This will compile the source files and generate the libft.a static library.

Example for **ft_printf**:
```bash
cd ft_printf
make
```
This will compile the source files and generate the libftprintf.a static library.
